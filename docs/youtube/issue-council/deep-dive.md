## Script (three lanes)

> **CAPTURE** = what's on screen · **SAY** = narration (Pass 2) · **ON-SCREEN** =
> text/arrows added in editing.

### 0:00 — Cold open / hook
- **CAPTURE:** Montage of patch-day complaints, then the Issue Council home.
- **SAY:** "Every big Star Citizen update, the same thing happens. Something
  breaks, the forums light up — and the developers say they can't reproduce it.
  There's a reason for that gap, and by the end of this video you'll be on the
  right side of it."
- **ON-SCREEN:** Title card: "How to Report a Star Citizen Bug."

### 0:20 — Why this matters (maps to pillar: "Why this matters right now")
- **CAPTURE:** Reddit/Discord B-roll, then the Issue Council.
- **SAY:** "The people who fix bugs don't read Reddit for their to-do list. They
  work from the Issue Council — the official bug site. A bug with no clear report
  there is one they may never find. One good report beats a thousand angry posts.
  Let's make that one good report."
- **ON-SCREEN:** "Bugs get fixed from the Issue Council — not social media."

### 0:50 — What the Issue Council is (maps to pillar)
- **CAPTURE:** Click around the signed-in Issue Council.
- **SAY:** "The Issue Council is a site run by the developers where players report
  bugs and confirm each other's reports. It's bugs only — design ideas and
  balance feedback go to Spectrum, the official forum. Post the wrong type and it
  gets archived."
- **ON-SCREEN:** "Bug? → Issue Council.  Idea/feedback? → Spectrum."

### 1:30 — Who can use it (maps to pillar: "Who can use it")
- **CAPTURE:** The Sign In flow.
- **SAY:** "One catch — you have to be a backer. Only people who own the game can
  sign in and contribute, using the same RSI account you log in with. If that's
  not you yet, there's a link below to start."
- **ON-SCREEN:** "Backers only · sign in with your RSI account"

### 2:00 — CHAPTER: Gather your evidence (maps to /gathering-evidence)
- **CAPTURE:** Launcher build number zoom.
- **SAY:** "Before you write anything, gather four things. First, your build
  number — it's under the Launch Game button in the Launcher. This tells the
  developers exactly which version you were on."
- **ON-SCREEN:** "1 of 4: Build number"

- **CAPTURE:** Explorer at StarCitizen\LIVE, Game.log + backups.
- **SAY:** "Second, your Game-dot-log. It's in your install folder, under
  StarCitizen, LIVE. It records what the game did and any errors. Copy it
  somewhere easy. The game keeps dated backups too, named by build number."
- **ON-SCREEN:** "2 of 4: Game.log  ·  ...\StarCitizen\LIVE\Game.log"

- **CAPTURE:** dxdiag → Save All Information → saved file.
- **SAY:** "Third, your system specs. Press Windows plus R, type dxdiag, let it
  load, and hit Save All Information. Some bugs only happen on certain hardware,
  so this matters."
- **ON-SCREEN:** "3 of 4: DxDiag (Win+R → dxdiag → Save All Information)"

- **CAPTURE:** In-game screenshot + short clip of the demo bug.
- **SAY:** "And fourth, a screenshot or a short video of the bug itself. For
  anything that moves, video wins. Show the problem and enough around it to see
  where you are."
- **ON-SCREEN:** "4 of 4: Screenshot / video"

### 4:00 — CHAPTER: Search before you file (maps to /searching-the-council)
- **CAPTURE:** Search box, results, status filter.
- **SAY:** "Now the step most people skip — search first. Sign in, search a few
  plain keywords for your bug, and try a second wording before you give up. If
  it's already reported, you add to that one instead of making a duplicate. Ten
  scattered reports help no one; ten people on one report move it up."
- **ON-SCREEN:** "Search first. Don't duplicate."

- **CAPTURE:** Open an existing report, show the "I can reproduce this" control.
- **SAY:** "Found it already there? Open it, confirm you can reproduce it, and
  add any detail it's missing. That's a complete contribution — you're done."
- **ON-SCREEN:** "Already reported? Add to it → you're done."

### 6:00 — CHAPTER: File the report (maps to /filing-a-report)
- **CAPTURE:** New report form — project/version/channel.
- **SAY:** "If it's genuinely new, file it. Pick the right version using your
  build number, and the channel — live game or the PTU test build. This points
  the developers at the right place."
- **ON-SCREEN:** "Version + channel"

- **CAPTURE:** Title field, then the good-vs-bad title comparison.
- **SAY:** "Write a title people can search. 'Game broken please fix' helps no
  one. 'Elevator at New Babbage spaceport doesn't arrive when called' — now
  someone with the same bug can find and confirm it."
- **ON-SCREEN:** "❌ 'Game broken'  ✅ 'Elevator at New Babbage doesn't arrive'"

- **CAPTURE:** Typing numbered reproduction steps.
- **SAY:** "Then the most important part — reproduction steps. The exact actions
  that make the bug happen, as a short numbered list. Where you were, what you
  did, what went wrong. If a developer can follow your steps and see it too,
  you've basically handed them the fix."
- **ON-SCREEN:** "Reproduction steps = the whole game"

- **CAPTURE:** Attach evidence, More info, Submit, confirmation.
- **SAY:** "Attach your screenshot, your DxDiag, and your log. Add anything else
  useful in the More info field — how often it happens, whether friends see it
  too. Then submit. That's a report a developer can actually act on."
- **ON-SCREEN:** "Attach evidence → Submit"

### 9:00 — CHAPTER: After you file (maps to /after-you-file)
- **CAPTURE:** The four status badges in turn.
- **SAY:** "Your report isn't the end. It moves through stages. Open means it's
  live and anyone can add to it. Around ten confirmations and it becomes
  Confirmed. Under Investigation means developers are on it. And Acknowledged
  means it's been copied into their internal tracker as a ticket."
- **ON-SCREEN:** "Open → Confirmed → Under Investigation → Acknowledged"

- **CAPTURE:** Clicking confirm on another report.
- **SAY:** "So here's the easiest way to help, even if you never file a single
  report — confirm bugs you also see. Every confirmation adds weight. Ten of them
  is the milestone."
- **ON-SCREEN:** "Confirm others = real help"

### 10:30 — Etiquette + outro
- **CAPTURE:** Site guide pages, then your end card.
- **SAY:** "Quick etiquette: one bug per report, stick to facts not opinions, and
  keep design gripes on Spectrum. Do all this and you're part of how the game
  actually improves. There's a full written version of everything here linked
  below, plus the 60-second version. If this helped, subscribe — I make Star
  Citizen plain-English. o7."
- **ON-SCREEN:** "Full guide → dayonecitizen.com/report-a-bug" + Subscribe.
