# Short — "Report a Star Citizen Bug the RIGHT Way (in 60 seconds)"

- **Length:** 60–90 seconds
- **Aspect:** vertical 9:16 (YouTube Shorts, TikTok, Reels, X)
- **Goal:** one fast, useful loop that ends by sending people to the long video
  and the written guide.

## Title options
- Report a Star Citizen bug the RIGHT way (in 60 seconds)
- The Star Citizen bug report that actually gets fixed
- Stop complaining on Reddit — do THIS instead (Star Citizen bugs)

## Thumbnail / cover text
Big bold: **"BUG REPORTS THAT WORK"** over a screenshot of the Issue Council. Or
a split: angry Reddit post (crossed out) vs. a clean Issue Council report (check).

---

## Silent capture checklist (Pass 1 — record these with no narration)
- [ ] RSI Launcher, slow pan to the build number under LAUNCH GAME
- [ ] File Explorer: the StarCitizen\LIVE folder with Game.log selected
- [ ] DxDiag running, then the Save All Information click
- [ ] Issue Council: type a search, show results
- [ ] Issue Council: a new report form with reproduction steps being typed
- [ ] Issue Council: clicking "I can reproduce this" on a report
- [ ] (optional) a clean shot of the site guide page on screen

---

## Script (three lanes)

> **CAPTURE** = what's on screen · **SAY** = narration (Pass 2) · **ON-SCREEN** =
> text/arrows to add in editing.

**Beat 1 — Hook (0:00–0:07)**
- **CAPTURE:** Fast montage — an angry forum/Reddit thread, then hard cut to the
  Issue Council site.
- **SAY:** "Found a bug in Star Citizen? Complaining online won't fix it. This
  will — in under a minute."
- **ON-SCREEN:** "Won't fix it ❌  →  Will ✅"

**Beat 2 — Grab your build number (0:07–0:17)**
- **CAPTURE:** RSI Launcher, zoom to the version under LAUNCH GAME.
- **SAY:** "One — your build number. It's right under the Launch Game button.
  Note it down."
- **ON-SCREEN:** "1. Build number" + arrow to the number.

**Beat 3 — Grab your logs and specs (0:17–0:30)**
- **CAPTURE:** Explorer at StarCitizen\LIVE with Game.log; quick cut to DxDiag →
  Save All Information.
- **SAY:** "Two — your evidence. Grab your Game-dot-log from the LIVE folder, and
  run dxdiag and save it. That's your system specs."
- **ON-SCREEN:** "2. Game.log + DxDiag"

**Beat 4 — Search first (0:30–0:40)**
- **CAPTURE:** Issue Council search box, type a keyword, show results.
- **SAY:** "Three — search the Issue Council first. If someone already reported
  it, add to theirs. Don't make a duplicate."
- **ON-SCREEN:** "3. Search before you file"

**Beat 5 — File it with clear steps (0:40–0:53)**
- **CAPTURE:** New report form — title, then numbered reproduction steps being
  typed, then attach.
- **SAY:** "Four — if it's new, file it. Clear title, the exact steps to make it
  happen, and attach your evidence. That's what gets it fixed."
- **ON-SCREEN:** "4. Steps + evidence = a real report"

**Beat 6 — Confirm to push it up (0:53–1:00)**
- **CAPTURE:** Clicking "I can reproduce this" on a report.
- **SAY:** "And five — confirm bugs you also see. Ten confirmations and the
  developers take notice."
- **ON-SCREEN:** "5. Confirm = 10 → developers notice"

**Beat 7 — CTA (1:00–1:10)**
- **CAPTURE:** The site guide page, then your handle/end card.
- **SAY:** "Full step-by-step guide and the long version are linked below.
  o7."
- **ON-SCREEN:** "Full guide → dayonecitizen.com/report-a-bug"
